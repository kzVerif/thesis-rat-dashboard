 ระบบนี้ใช้ Cookie Session ดังนั้นหลัง login สำเร็จ Browser จะเก็บ __Host-session และส่งกลับให้อัตโนมัติทุก request ที่ต้องยืนยันตัวตน

  ## ลำดับการใช้งาน

  สมัครสมาชิก
     ↓
  Login → ได้ Session Cookie
     ↓
  เรียก /me, /sessions, change-password ฯลฯ
     ↓
  Logout → Session ถูกยกเลิก

  ## 1. สมัครสมาชิก

  POST /register

  ใช้สร้างบัญชีใหม่ก่อน login

  Request:

  {
    "username": "john",
    "fullname": "John Doe",
    "email": "john@example.com",
    "password": "password123",
    "confirmPassword": "password123"
  }

  ตัวอย่าง fetch:

  await fetch("http://localhost:8080/register", {
    method: "POST",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      username: "john",
      fullname: "John Doe",
      email: "john@example.com",
      password: "password123",
      confirmPassword: "password123"
    })
  });

  หมายเหตุ: ในฐานข้อมูลต้องมี role ชื่อ VIEWER ก่อน:

  INSERT INTO roles (name, description)
  VALUES ('VIEWER', 'ผู้ใช้งานทั่วไป')
  ON CONFLICT (name) DO NOTHING;

  ———

  ## 2. Login

  POST /api/auth/login

  ตรวจ username และ password จากนั้นสร้าง session อายุ 7 วัน

  Request:

  {
    "username": "john",
    "password": "password123"
  }

  ตัวอย่าง fetch:

  const response = await fetch("http://localhost:8080/api/auth/login", {
    method: "POST",
    credentials: "include",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      username: "john",
      password: "password123"
    })
  });

  const data = await response.json();
  console.log(data);

  เมื่อสำเร็จ Server จะส่ง:

  Set-Cookie: __Host-session=<token>

  และบันทึกข้อมูลต่อไปนี้ลง user_sessions:

  - Hash ของ session token
  - เจ้าของ session
  - IP address
  - User-Agent หรือข้อมูล Browser
  - เวลาสร้าง
  - เวลาหมดอายุ
  - เวลาที่ใช้งานล่าสุด

  ———

  ## 3. ดูข้อมูลผู้ใช้ปัจจุบัน

  GET /api/auth/me

  ใช้ตรวจว่า login อยู่หรือไม่ และดึงข้อมูลบัญชีปัจจุบัน

  const response = await fetch("http://localhost:8080/api/auth/me", {
    credentials: "include"
  });

  const user = await response.json();
  console.log(user);

  ตัวอย่างผลลัพธ์:

  {
    "id": "user-uuid",
    "username": "john",
    "email": "john@example.com",
    "display_name": "John Doe",
    "role": "VIEWER"
  }

  ถ้าไม่มี session หรือ session หมดอายุ:

  {
    "error": "unauthorized"
  }

  พร้อม HTTP status 401

  ———

  ## 4. ดู Session ทั้งหมด

  GET /api/auth/sessions

  ใช้ดูว่า Account นี้ login อยู่ใน Browser หรืออุปกรณ์ใดบ้าง

  const response = await fetch("http://localhost:8080/api/auth/sessions", {
    credentials: "include"
  });

  const data = await response.json();
  console.log(data.sessions);

  ตัวอย่างผลลัพธ์:

  {
    "sessions": [
      {
        "id": "session-uuid",
        "ip_address": "127.0.0.1",
        "user_agent": "Mozilla/5.0 ...",
        "created_at": "2026-08-08T15:30:00Z",
        "last_activity_at": "2026-08-08T15:45:00Z",
        "expires_at": "2026-08-15T15:30:00Z",
        "current": true
      }
    ]
  }

  current: true หมายถึง session ของ Browser ที่กำลังเรียก API นี้อยู่

  ———

  ## 5. ลบ Session ที่เลือก

  DELETE /api/auth/sessions/:id

  ใช้สั่ง logout อุปกรณ์ใดอุปกรณ์หนึ่ง เช่น ต้องการให้ออกจากระบบเฉพาะเครื่องที่ไม่รู้จัก

  นำ id จาก /api/auth/sessions มาใส่ใน URL:

  const sessionID = "session-uuid";

  const response = await fetch(
    `http://localhost:8080/api/auth/sessions/${sessionID}`,
    {
      method: "DELETE",
      credentials: "include"
    }
  );

  console.log(await response.json());

  ระบบตรวจด้วยว่า session ID นั้นเป็นของผู้ใช้ปัจจุบัน จึงไม่สามารถใช้ลบ session ของคนอื่นได้

  ถ้าลบ session ปัจจุบัน Browser เครื่องนี้ก็จะถูก logout ด้วย

  ———

  ## 6. Logout เครื่องปัจจุบัน

  POST /api/auth/logout

  ใช้ logout เฉพาะ Browser หรืออุปกรณ์ที่กำลังใช้งานอยู่

  const response = await fetch("http://localhost:8080/api/auth/logout", {
    method: "POST",
    credentials: "include"
  });

  console.log(await response.json());

  ระบบจะ:

  1. กำหนด revoked_at ให้ session ปัจจุบัน
  2. บันทึกเหตุผลเป็น logout
  3. ลบ __Host-session ออกจาก Browser

  Session ของอุปกรณ์อื่นยังใช้งานต่อได้

  ———

  ## 7. Logout ทุกอุปกรณ์

  POST /api/auth/logout-all

  ใช้ยกเลิกทุก session ของบัญชี เช่น สงสัยว่าบัญชีถูกขโมย

  const response = await fetch(
    "http://localhost:8080/api/auth/logout-all",
    {
      method: "POST",
      credentials: "include"
    }
  );

  console.log(await response.json());

  หลังเรียกแล้วทุก Browser และทุกอุปกรณ์ต้อง login ใหม่

  ———

  ## 8. เปลี่ยนรหัสผ่าน

  POST /api/auth/change-password

  Request:

  {
    "current_password": "password123",
    "new_password": "newPassword456",
    "confirm_password": "newPassword456"
  }

  ตัวอย่าง:

  const response = await fetch(
    "http://localhost:8080/api/auth/change-password",
    {
      method: "POST",
      credentials: "include",
      headers: {
        "Content-Type": "application/json"
      },
      body: JSON.stringify({
        current_password: "password123",
        new_password: "newPassword456",
        confirm_password: "newPassword456"
      })
    }
  );

  console.log(await response.json());

  ระบบจะ:

  1. ตรวจรหัสผ่านปัจจุบัน
  2. ตรวจรหัสใหม่อย่างน้อย 8 ตัวอักษร
  3. ตรวจรหัสใหม่ไม่ซ้ำกับรหัสเดิม
  4. Hash รหัสใหม่ด้วย bcrypt
  5. บันทึกรหัสใหม่
  6. ยกเลิกทุก session
  7. บังคับให้ login ใหม่

  ## จุดสำคัญเรื่อง Cookie

  ทุก request ที่ต้อง login ต้องใส่:

  credentials: "include"

  โดยเฉพาะกรณี frontend กับ backend คนละ port เช่น:

  Frontend: http://localhost:5173
  Backend:  http://localhost:8080

  นอกจากนี้ cookie ปัจจุบันตั้ง:

  Secure=true

  เพราะชื่อ __Host-session ต้องเป็น Secure Cookie ดังนั้นสำหรับการใช้งานจริงควรเปิด Backend ผ่าน HTTPS หากทดสอบ HTTP แล้ว Browser ไม่เก็บ cookie จะต้องทำโหมด development แยก หรือใช้ HTTPS สำหรับ localhost ครับ
